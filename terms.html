OzcanKlip Uploader — Hizmet Şartları

Son güncelleme: 8 Eylül 2026

1. Hizmetin Niteliği

OzcanKlip Uploader; Yiğit Kıvrak'ın (aşağıda "Geliştirici") kendi YouTube kanalı "Özcan Shorts" üzerinde kullanımı için geliştirdiği kişisel bir masaüstü yazılımıdır. Herkese açık bir servis değildir; abonelik, üyelik veya kullanıcı kaydı yoktur.

2. Kapsam

Yazılım; Geliştiricinin kendi hazırladığı videoları kendi kanalına YouTube Data API v3 (videos.insert) ile yüklemesine yardımcı olur. Başkaları adına işlem yapmaz, içerik barındırmaz, dağıtım yapmaz.

3. API Kullanımı

Yazılım yalnızca kanal sahibinin kendi OAuth onayıyla aldığı yetkiler çerçevesinde çalışır (youtube.upload, youtube.readonly). YouTube API Hizmetleri Şartları ve YouTube'un Geliştirici Politikaları'na uyulur. Verilerin işlenmesine ilişkin ayrıntılar Gizlilik Politikası'nda yer alır.

4. Sorumluluk Sınırlaması

Yazılım "olduğu gibi" sunulur; Geliştirici, yazılımın kullanımından doğabilecek arıza veya veri kayıpları için bilinen sınırlar içinde sorumluluk taşımaz. YouTube hizmet koşullarının uygulanması YouTube'a aittir.

5. Fesih

Geliştirici, Google hesabı ayarlarından uygulamanın erişimini herhangi bir zamanda iptal edebilir; bu, belirteçlerin silinmesiyle tamamen geçerliliğini yitirir.

English Summary

OzcanKlip Uploader is a personal desktop tool used solely by its developer to upload his own videos to his own YouTube channel via the YouTube Data API. It is not a public service: no accounts, no fees, no third-party users. API use is limited to videos.insert with the owner's own OAuth consent. See the Privacy Policy for data handling.
